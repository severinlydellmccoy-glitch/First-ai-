# Which print provider do our sweatshirts and hoodies use, and its Christmas date?

Please read the print_provider_id of the live sweatshirt and hoodie products from the Printify API (read-only) and record the provider name in CLAUDE.md, so the next Scout run can look up its exact Standard deadline.
