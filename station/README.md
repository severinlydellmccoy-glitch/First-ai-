# Station

A top-down map of the business, laid out like a space station. Each room is one part of the business: lit rooms exist in this repository, and orange blueprint outlines are planned but not built yet. The robots are the AI agents; a lit visor means the agent is set up.

**View it:** https://claude.ai/artifact/FX7jK2pgAyh9GkJi99JLAh (private to the owner's claude.ai account).

`index.html` is a backup copy of the same page. Claude updates both whenever a module, folder or agent changes, so the station always matches the repository.
