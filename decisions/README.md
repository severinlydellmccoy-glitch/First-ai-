# Decisions

The Boss's decisions about what the station works on next. One file per decision round, named `YYYY-MM-DD-decisions.md`.

Each file lists the ideas picked to make next, the ideas put on hold, the reason for each, and anything that needs the owner (money, accounts or investments).

`owner-todo.md` is the owner's living to-do list. The Boss keeps it up to date every run: the three "Do next" items at the top, then everything else with checkboxes.
